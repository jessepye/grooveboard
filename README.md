# GrooveBoard

An extremely simple, intuitive, and real-time collaborative whiteboard application. Designed for ease of use (even for younger users) by maintaining a single, non-zoomable page interface.

## Try the prototype

The current UI is a design prototype in `grooveboard-claude-design/`. No build step is needed:

```bash
cd grooveboard-claude-design && python3 -m http.server 8000
# then open http://localhost:8000/GrooveBoard.html
```

See `docs/roadmap.md` for where the project is headed.
